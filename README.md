# 魂斗罗 · 第一关（网页版 Demo）

一个用于测试的 HTML5 网页版魂斗罗第一关小游戏，纯原生 JavaScript + Canvas 实现，无任何依赖。

## 怎么玩

直接用浏览器打开 `index.html` 即可。

| 按键 | 操作 |
|------|------|
| ← → / A D | 移动 |
| 空格 | 跳跃 |
| J / X | 开火 |
| ↑（按住） | 向上射击 |
| Enter | 开始 / 重新开始 |

## 内容

- 横版卷轴关卡（丛林夜景，视差背景）
- 三种敌人：冲锋兵、狙击手、炮台
- 关底 Boss「要塞之门」（30 点血）
- S 散弹枪道具、水坑陷阱、检查点复活
- 3 条命、计分系统、WebAudio 合成音效
